# Robotman Domain

Terms for Robotman's Discord server features and dashboard.

## Servers and access

**Guild**:
A Discord server where Robotman may be installed and used.

**Managed Guild**:
A guild whose owner or a member with Manage Server or Administrator permission can manage its Robotman settings.

**Bot Installation**:
Robotman's authorization in a guild, which makes its server features available there.

## Responses

**Response**:
Saved text or embed content returned when a person requests it with a trigger.

**Trigger**:
The exact phrase a person enters to request a Response. Matching ignores letter case.

**Alias**:
An additional exact phrase that requests the same Response as its primary trigger.

## Recommendations

**Recommendation Entry**:
A named collection of recommended works in one of four categories: character, writer, moderator, or booster.

**Recommendation Directory**:
The browsable index of available Recommendation Entries, organized by category.

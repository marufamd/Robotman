# Keep recommendation replies independent with full Response editing capabilities

**Status: accepted**

Recommendation Entries own freely authored text and embeds independently of Responses, while sharing their editing, validation, placeholder and preview capabilities. The simplified name/description/link model cannot preserve the original bot's authored collections, and linking entries to Responses would make edits unexpectedly change unrelated replies. Recommendation names, aliases and categories govern discovery; Moderator and Booster curator attribution and overridable introductions add context without imposing structured book records or live Discord membership dependencies.
